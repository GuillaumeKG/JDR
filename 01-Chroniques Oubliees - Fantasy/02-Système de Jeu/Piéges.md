# Piége

## Généralité


Pour éviter un piège vous pouvez soit le contourner, soit tenter de le désamorcer.  



## Détection
Si le personnage ne cherche pas particulièrement de piège:
- Réussir un test de SAG de DD définie par le piège

Si le personnage cherche activement un piège:
- Réussir un test de  INT de DD du piège -5
- Limite le déplacement à 3m/tour => 1km/h => 4km par période


## Désamorçage
Dépendant du piège, réussir un test de DD et type définis par le type de piège.
