# Tests


## Réalisation
1. Lancer 1 D20 

2. Ajouter Bonus/Malus au score du dé correspondant à la caractèristique utilisée pour le test

3. Dépend du type de test, il y a principalement 2:
    * Contre un [Degré de Difficulté](#degré-de-difficulté) définit par le MJ  
        => Test réussi si le score du PJ est >= au DD

    * Contre un PNJ
        => Test réussi si le score du PJ est >= au score du PNJ  

## Critiques
Il y a 2 type de lancer particuliers (dit naturel avant application des modificateurs) :
- **Echec Critique**  
    Généralement la valeur est uniquement **1**, mais peut changer.  
    Inmplique un échec automatique du test ainsi qu'un effet défavorable pour le PJ.  

- **Réussite Critique**  
    Généralement la valeur uniquement **20**, mais peut changer.  
    Implique un succès automatique du test ainsi qu'un effet favorable pour le PJ.

## Test en coopération

Des compagnons peuvent assister un des leur lors d'un test. 

Pour être en mesure d'assister un autre joueur, les conditions suivantes doivent être remplies. Le joueur qui aide doit : 
  - Etre proche du joueur réalisant le test  
  - Posséder une compétence qui justifie logiquement qu'il peut l'aider

L'aide compte comme une action limitée (remplace 1 mouvement + 1 attaque).  
Le joueur recevant l'aide doit jouer après le joueur qui l'aide. Il peut retardé sont tour si besoin pour agir après le joueur aidant.  

Si toutes les conditions sont vérifiées :  
- Le joueur aidant effectue un test de DD10 sur la carac du test en cours
    - Si réussi:  
        => +2 au test principal (+4 si succès critique)  
        Alternative: A la place le test gagne avantage.
    - Si échec:  
        => Rien

## Prendre son temps
Pour améliorer ses chances de réussite, un personnage peut décide de prendre son temps.

Pour une action normale:  
* Prends 2d6 minutes  
    => Obtient un 10 naturel
* Prends 2d6 heures  
    => Obtient un 20 naturel (non critique)
