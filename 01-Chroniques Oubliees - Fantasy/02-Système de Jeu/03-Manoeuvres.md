# Les Manoeuvres

## Overview

2 types de manoeuvres : 
  - **Manoeuvre risquée**  
     1. Annoncez la manoeuvre et effectuez un test d'attaque opposé
        - Si le test est réussi :
           - La manoeuvre s'applique
        - Sinon :
          - La cible fait subir à l'attaquant l'effet de son choix

  - **Manoeuvre d'usure**  
     1. Annoncez la manoeuvre et effectuez un jet d'attaque normal : 
        - Si le test est réussi :
           - La cible choisit :
             - Subir l'effet de la manoeuvre
             - Subir les DM normalement
