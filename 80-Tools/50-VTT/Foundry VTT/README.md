## Interface

- **Zone centrale**  
    Appelée le canevas, elle permet d'afficher les scéne que vous créez.  


- **Barre de navigation (en haut)**
    Affiche la scéne actuelle et d'autres à accéder.  
    Permet au MJ de contrôler : 
        - Quelles Scénes sont visible
        - Quelle est la scéne active
        - 

- **Barre latérale droite**  
    Ensemble des menus, comprenant : 
      - Tchat
      - Combat
      - Scènes
      - Acteurs
      - Items
          Tout ce qui peut être donner aux PJ
      - Journaux
        Stocke les détails important du monde, des pnj, des quêtes...
        Vous pouvez créer une entrée par joueur pour leurs prises de notes.
      - Tables aléatoires
      - Jeu de cartes
      - Playlist
      - Compendium
        Configurer les acteurs, objets...
      - Paramètres




- **Barre latérale gauche**  
    Outils de contrôle de scéne : 
      - Murs
      - Lumiéres
      - Tokens
      - ...

- **Barre centrale du bas**  
    Contient des raccourcis pour un accès rapide ou l'éxecution de macros.  

- **En bas à gauche**  
  Liste des joueurs connectés avec leur personnage principal.
