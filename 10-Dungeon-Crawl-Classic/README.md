## Tests



### Test

 1. Définition de la difficulté : 
    - Hors combat  
      Le MJ définit un DD pour le test
    - En combat  
      Le DD est la CA
 2. Le PJ lance le dé et applqiue les modificateurs
 3. Si résultat >= DD : Succès




2 cas particuliers : 
- 1 Naturel : Echec automatique + maladresse
- 20 Naturel : Succès automatique + réussite critique



### Jet de compétence

1. Lancer 1D20
    - Faveur : 2D20 gardez le plus bas
    - Fléau :  2D20 gardez le plus haut
2. Si le résultat =< niveau de compétence => Succès


### Jet de sauvegarde

Il y en a de 3 types:
- **Vigueur**  

- **Réflexes**  

- **Volonté**  




### Test d'incantation

Test utilisé pour lancer un sort.
Plus le résultat est haut, plus l'effet est fort.
