# Création de personnage


## Overview




## Profil  
Chaque joueur choisit 1 profil qui représente son activité principale.  

Il existe 4 familles : 

    |Famille|PV|Bonus Carac.|
    |--|:--:|--|
    |Combattant|5||
    |Aventurier|4|+1 PC|
    |Mage|3|+1 capa rang 2|
    |Mystique|4|+1 DP|

Chaque famille définit : 
    - Les points de Vigueur
    - Les points de Chance
    - Les dés de Récupération
    - Les capacités réparties en 5 Voies
    - L'équipement utilisable



## Peuple  
Le peuple apporte : 
  - Des modifications de caractèristiques
  - 1 voie de peuple 

Les peuples disponibles sont : 
  - Demi-Elfe
  - Demi-orc
  - Haut Elfe
  - Elfe Sylvain
  - Gnome
  - Halfelin
  - Humain
  - Nain

## Caractèristiques  
Liste :
  - **Physique**
  - Agilité
  - Constitution  
  - **Spirituel**  

Pour définir les valeurs :
1. Choisir un style listant les modificateurs disponibles à répartir entre ses caracs :   
     - **Polyvalent**  
        +2, +2, +2, +1, +1, 0, -1

      - **Expert**  
        +3, +2, 1, 1, 0, 0, -1

      - **Spécialiste**  
        +4, +2, +1, 0, 0, -1, -1

2. Appliquez les modificateurs de peuple
